# 科研新手文献辅助汇报工具 · 可运行原型

这是课程项目的第一版框架，重点验证“先理解论文 → 人工确认汇报大纲 → 再生成网页幻灯片”的流程。

## 启动

需要 Node.js 18 或更新版本。项目已经附带 PDF 解析文件，无需安装依赖。

1. 在本文件所在文件夹打开终端。
2. 运行 `node server.mjs`。
3. 浏览器打开 `http://127.0.0.1:4173`。

Mac 用户也可以双击 `启动原型.command`。启动时会询问 DeepSeek API Key；粘贴后按回车即可，输入不会显示在屏幕上。直接按回车则进入演示模式。关闭启动窗口后需要下次重新输入，密钥不会保存在项目文件中。如果系统阻止首次打开，可在终端按上述方式启动。

### DeepSeek 接入步骤（Mac）

1. 到 [DeepSeek 开放平台](https://platform.deepseek.com/)登录，在「API Keys」中新建并复制一把 Key；确认账号有可用额度。
2. 关闭之前运行原型的终端窗口。浏览器里旧的 `file://.../public/index.html` 标签也可以关闭。
3. 双击本文件夹中的 `启动原型.command`。在终端提示处粘贴 Key，按回车；粘贴时不会显示字符，这是正常的。不要把 Key 填在网页里。
4. 等浏览器自动打开 `http://127.0.0.1:4173`，检查右上角显示「DeepSeek 模式可用」。上传文字型 PDF 后，分析完成会显示「DeepSeek 辅助梳理」。

如果右上角仍显示「演示模式可用」，请关闭启动窗口后重新双击，并确认输入的 Key 不是空的。如果出现 API 错误，请先检查 Key 是否有效、账号是否有额度，然后按页面显示的错误信息排查。

没有模型接口密钥时，点击“使用演示材料体验流程”，或上传文字型 PDF，系统会使用**规则提取演示模式**。它只从原文截取可能相关的句子，不能替代 AI 理解或人工阅读。界面会明确标注当前模式。

如需真实 AI 辅助梳理，请使用 [DeepSeek 官方开放平台](https://platform.deepseek.com/)创建 API Key。推荐双击 `启动原型.command`，按提示输入。若从终端启动，可先设置环境变量 `DEEPSEEK_API_KEY`；`DEEPSEEK_MODEL` 可选，默认使用 `deepseek-flash`，也可填官方支持的 `deepseek-v4-pro`。

```sh
read -rs "DEEPSEEK_API_KEY?请粘贴 DeepSeek API Key："; echo
export DEEPSEEK_API_KEY
node server.mjs
```

密钥只保留在本地服务的环境变量中，不会写进网页文件。启用后，提取的论文文字会被发送到 DeepSeek，用于生成理解卡片和汇报大纲。当前原型最多向模型发送约 8 万字符；较长论文的后半部分可能不在分析范围内。DeepSeek 调用按其平台计费；请在开放平台查看余额和实际用量。

## 已实现

- 上传 25 MB、100 页以内的文字型 PDF，在浏览器中按页提取文本；扫描版 PDF 暂不支持。
- 根据论文文本生成“背景、问题、方法、研究设计、结果、结论”理解卡片；卡片保留 PDF 顺序页码。
- “理解论文”页增加九类可展开的阅读框架：论文信息、相关研究、研究问题、研究路径、方法、结果与图表、结论与局限、一分钟速览和论文逻辑链。DeepSeek 模式区分原文信息、基于原文的解释及原文未说明的内容；规则演示模式只能提供有限摘录，空白栏目需自行补充。
- 根据论文内容生成最多 10 页的可编辑大纲：页数与侧重点不固定，并说明安排依据；用户可以修改标题、核心观点、补充要点和页码，添加、删除或调整顺序。
- **大纲确认关口**：未确认无法生成页面；确认后返回编辑内容，需要重新确认。
- 根据大纲生成 HTML 幻灯片，切换 5 类版式和 3 套配色，调整字号、图片大小，上传图片或插入 PDF 页面截图。
- 每张幻灯片下方显示可编辑的演讲稿草稿：根据已确认的本页观点和要点整理，切换页面时保留各自内容；可复制本页讲稿。修改大纲后，手动改过的讲稿会提示重新检查。
- 首次分析后将 PDF、提取文字、分析结果、大纲、版式和讲稿保存在当前浏览器。刷新时恢复最近的项目；再次导入内容完全相同的 PDF 时复用本地分析，不再次调用 DeepSeek。
- 浏览器打印或保存为 PDF。

## 当前边界

- 页面是 HTML 幻灯片，尚未导出可编辑的 `.pptx` 文件。
- 演讲稿是依据已确认大纲整理的初稿，不会凭空补充论文细节；打印或保存幻灯片 PDF 时不包含讲稿。
- 图片功能支持用户上传和插入 PDF **整页截图**，尚未自动识别并裁切论文图表。
- 未配置模型接口时仅为规则提取演示：会根据找到的内容改变大纲，但仍可能误判论文类型或错找段落，不能作为可靠的论文摘要。
- 模型只接收提取到的文字，不能直接“看懂”论文里的图片；图表解释必须有正文描述支持。输入过长时只发送前约 8 万字符，页面后部可能未被分析。
- 版式 Skill 当前由 `版式Skill.md` 中的规则和 `public/styles.css` 中的五类模板实现；尚未让模型自动设计新模板。
- 本地记录保存在浏览器的 IndexedDB 中，文字修改另有即时本地草稿；不会上传到其他存储服务。更换浏览器、清除网站数据或改用不同地址／端口会看不到原记录。同一论文的判断基于 PDF 文件内容；重新导出后文件字节改变，可能被视为新文件。仍建议另外保留论文原件和重要讲稿。首次启用这一功能前已经打开的旧页面状态无法自动迁移，需要重新导入一次。

## 文件说明

- `server.mjs`：本地网页服务与模型接口。
- `src/analysis.mjs`：规则提取演示与输出检查。
- `public/app.mjs`：PDF 读取、页面交互、大纲确认与幻灯片渲染。
- `public/styles.css`：网页界面和幻灯片模板。
- `版式Skill.md`：页面规则，供后续迭代版式和讨论 AI Skill 使用。
